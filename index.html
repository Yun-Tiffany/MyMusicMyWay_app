      1. 到 Google Cloud Console 建一個新專案（名字隨便取，例如「我的播放器」）。
      2. 到 YouTube Data API v3 頁面按「啟用」。
      3. 到 OAuth 同意畫面：使用者類型選「外部」，填 app 名稱和你的 Gmail；在「目標對象／測試使用者」把你自己的 Gmail 加進去。

      5. 把產生的「用戶端 ID」複製，貼到上面的格子。它會記在這台瀏覽器裡（手機和電腦各要貼一次）。之後按「登入 YouTube，從我的清單匯入」就能選自己的清單，連私人清單和按讚的歌都可以。
